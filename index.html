🔭趋势观察

  • 1

    榜单仍是「给 agent 装手艺」的天下：Claude-BugHunter、superpowers、diagram-design、last30days、stitch-skills、autoclip 加上周榜的 plannotator，20 个项目里近半是把某类专业能力封装成 skills，而不是造模型。

  • 2

    「评审与回传」成了新的稀缺环节：plannotator 做批注工作台、阿里开源 open-code-review 做规模化代码评审、opensre 直接读失败 CI 并提交待审修复——竞争焦点从「会写」转向「写完谁把关、怎么闭环」。

  • 3

    MCP 从「接得上」进入「怎么管」：opencode 同日提交了加载 MCP skill 前先询问、每版本只问一次、技能声明在会话池中不丢失、工具报错不返回空结果，权限与可信度正在成为协议层的一等需求。

  • 4

    终端的价值被重新发现：pi v1.7.0 支持重启后恢复原会话（含 profile、工具限制、指令），说明编码 agent 的竞争力越来越落在「长期会话的连续性」而非单次生成质量。

  • 5

    本地优先与自托管继续是有效叙事：nod 自带「电脑」在真实网站跑腿但坚持本地运行、自选模型、行动前先问；autoclip 零订阅、openvino 与 AMD llama.cpp 补硬件生态，都在卖「跑在自己机器上」。
