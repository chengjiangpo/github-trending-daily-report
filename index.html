🔭趋势观察

  • 1

    榜单又被「给 agent 加技能、加手、加入口」的项目包场：modern-web-guidance、anthropics/skills、mattpocock/skills、agent-browser、OpenMausBot、EGM、plannotator 全是这一类，而且背后是 Chrome/Edge/Firefox、Google、Anthropic、Vercel 亲自下场——skill 已成厂商分发能力的新单位。

  • 2

    代码审查是 agent 最先被产品化的场景：阿里 open-code-review 与 OpenAI codex-security 同日上榜，一个卖「确定性工程 + agent、token 省 9 倍」，一个卖安全扫描到修复的闭环，共同点是把「验证与证据」放在聊天之上。

  • 3

    端侧与本地优先继续升温：OpenMausBot 把 Claude/Codex 装进桌面当联系人，Veyra 用 GPU 实时增强主机串流，agent-browser 用 Rust 做原生 CLI，「跑在自己机器上、用自己已有的模型」是共同卖点。

  • 4

    企业语义层开始被整层开源：NVIDIA auto-ontology 直面「agent 查数不准」，与上周 DeepSeek 开源推理栈同构——大厂开源的不再是单点工具，而是抢 agent 生态标准位的底座。

  • 5

    财务与交易类项目同日扎堆（sure、claude-trading-skills、daily_stock_analysis），说明 agent 正被推向有真金白银后果的场景；这类 README 普遍在顶部写免责声明，也说明作者清楚风险边界在哪。
