🔭趋势观察

  • 1

    今天榜单里 agent 相关项目占了 11/20，但重心从「给 agent 加技能」转向「给 agent 修基础设施」：agy-fast 用批量本地 MCP 调用把 TTFT 与空转卡顿打下来，fast-anything 只重写 5% 热点，deslop-please 用 linter 卡住 AI 生成的糊弄代码，skill-distill 则把老师模型的成功会话压成小模型能执行的 skill。

  • 2

    「把一项专家工作固化下来」仍是最高效的爆款公式：Jane Street 只放出一个苏格拉底式教学 skill 就拿到 1.1 万星，unslop 把「反 AI 味」做成可复用流程，skill-distill 把整段会话蒸馏成可复现技能——skill 正在变成可分发的工程资产。

  • 3

    本地化与端侧是另一条主线：Mika 在隐藏屏幕里替你操作手机 App、PiBot 用 pi 内核在桌面上组 agent 团队、songe 拿你的闲置算力训练本地模型、agent-sim 让 agent 在 Linux 上跑 iOS 模拟器——都在把执行与数据留在用户设备上。

  • 4

    游戏静态重编译成了一个独立的小生态：VIctory（GTA VI）与 xcl（Xbox 兼容层）分别拿下 1.1 万与 7.7 千星，同一主题还有多个 fork 与「进度追踪」仓库；VIctory 的 README 老实写着「还不能玩、每帧 1-2 秒」，热度明显跑在可玩性前面。

  • 5

    安全侧出现对称动作：一边是 agentic-attack-detections 为 PentAGI、HexStrike 这类「AI 攻击框架」写检测规则，一边是 OpenAI 与 Cisco 开源 Shirudo 帮未打补丁的 Linux 撑过修复窗口——agent 攻防开始有专门的工具链。
