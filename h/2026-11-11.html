  • 1

    「让 agent 有一双手」是今天最密集的一条线：pinky 与 poki 都在把真机 iPhone/Android 交给 agent，且都把安全边界做进网关而不是提示词；S2Arm 给启动器配了 s2armctl、craft-anything 把 320 个能力全做成 MCP tool、rune 让 UI 可 headless 渲染供 agent 自检——agent 的可操作面正在从终端扩到手机与图形界面。

  • 2

    《时之笛》重编译出现「双雄合并」：Hookshot 冲到 6.6k star，ocarina-recomp 直接在 README 里推荐对手并转为贡献者，同机对比、存档通用的细节写得很实在，这是开源竞品少见的良性收束。

  • 3

    DeepSeek 生态继续外溢：DeepInfer（官方推理框架）、dsh-superagent-prototype（官方主动型 agent）、dsh-Go（第三方 Android 客户端）三条同榜，且都强调「手机/本机可跑」，harness 正在长出完整的分发层。

  • 4

    成本与效率项目霸榜且都给硬数字：TokenEconomizer 用 SWE-Bench 证明平均省 18–31%，gpu-unlock 用 TFLOPS 表格说明消费卡被限速，cleanyourtv 以 5.6 万 star 说明「去广告」仍是最大众的诉求。

  • 5

    接口级「越狱式」工具热度不减：GestaltX 用 MobileGestalt 预设改机型能力（甚至尝试在中国大陆机型上开 Apple Intelligence），与游戏重编译、去广告桌面共享同一种气质——用户不愿等平台开放，就自己把开关拨过去。
